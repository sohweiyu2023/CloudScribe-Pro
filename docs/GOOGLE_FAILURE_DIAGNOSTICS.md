# Safe Google synthesis failure diagnostics

HTTP status and canonical `error.status` are recorded independently from queue admission decisions. A completed error response does not prove no charge and does not authorize retry. Keep existing reservations and inspect the durable request identity before any separately approved recovery.

Local event 1604 additionally records fixed enum categories derived from `google.rpc.ErrorInfo` and `google.rpc.BadRequest`, when the provider actually supplies those structured details. Parsing is bounded to 16 KiB, JSON depth 8, 16 detail entries and 16 field violations. Duplicate or malformed consumed fields produce Unknown. Unsupported values never become log strings.

The reason allowlist covers documented Service Infrastructure reasons in the `googleapis.com` domain: service/billing disabled, invalid or service-blocked API key, rate/resource quota exceeded, invalid consumer, expired token and insufficient token scope. Domain categories recognize only `googleapis.com` and `texttospeech.googleapis.com`; service-specific reasons without an explicit allowlist remain Unknown. Request-field categories recognize the fixed text/SSML, voice and audio-configuration field names. Multiple recognized fields become Multiple. Unknown fields become Unknown. These categories are diagnostic only, never synthesis permission, retry evidence or budget settlement.

The parser does not inspect or retain `error.message`, field descriptions, `ErrorInfo.metadata`, localized messages or raw details. It cannot recover a detailed reason from an earlier response that was already discarded. Missing structured details remain NotProvided rather than a guessed cause.

The source passes the exact compiled byte array through the provider adapter into `ByteArrayContent`; an offline HTTP-handler test verifies byte equality, including escaped Unicode. The stage payload SHA identifies the supplied compiled bytes. This is not a packet capture of historical requests and does not prove an unrecorded per-attempt URI. A request below the existing 5,000-byte compiled-envelope guard should not be blamed on that cap without an actual wire invariant failure. No undocumented sentence-length limit is imposed. One successful part does not certify all Chirp requests.

Canonical schemas and allowlist references: [Google AIP-193](https://google.aip.dev/193), [Google Service Infrastructure error reasons](https://github.com/googleapis/googleapis/blob/master/google/api/error_reason.proto), [ErrorInfo](https://docs.cloud.google.com/php/docs/reference/common-protos/latest/Rpc.ErrorInfo), [BadRequest.FieldViolation](https://docs.cloud.google.com/php/docs/reference/common-protos/latest/Rpc.BadRequest.FieldViolation). Provider content limits: [Text-to-Speech quotas](https://docs.cloud.google.com/text-to-speech/quotas).
