# Follow the controls in CloudScribe

Choose **Help** to open the live walkthrough. New profiles open it automatically. The yellow and black outline identifies a real control you can use while the guide is open. **Show control** scrolls it into view and focuses it when enabled. **Back**, **Next**, **Skip guide** and **Finish guide** only navigate help; they never approve a cost, configure a credential or generate speech. Escape skips; Tab reaches controls and the guide buttons. There is no global Enter shortcut that could submit a request.

There are 15 steps for a first connection and 11 for a saved connection. The guide moves between Studio, Google connection setup and Create MP3. Back also works across these windows. A saved connection is reused; choose **Include Google setup guide** in the Studio guide to see the external setup instructions when needed. Do not replace a working saved connection just to follow the guide.

The guide covers a short local paragraph, the Create MP3 entry point, Google project/billing/API setup, a private service-account JSON, connection validation, saved voices, catalog refresh, voice selection, pricing verification, exact cost review, explicit consent, billable creation, playback/export and returning later. Google routes are labeled illustrations based on official documentation, not screenshots of an account. Open their official links for current prerequisites and permissions. Never share a key or put it in a document or screenshot.

The guide sits beside wide windows and below narrow ones. Its text scrolls independently and its navigation stays reachable. It expands relevant sections, follows live control geometry and clips highlights to visible viewports. On small Studio windows, the player and Focus button are temporarily hidden to leave room for the actual editor; they return when the guide closes. If a control is missing or scrolled away, the guide says so and offers Show control or Next. It never falls back to guessed screen coordinates.

Your saved files and connection are not changed by guide navigation. Finishing or skipping remembers only that first-run help was seen, using the existing preferences format. Preferences, account metadata and documents survive restart. Access checks expire and every billable request needs fresh consent. In-app verified MP3 playback/export remains session-only; older MP3s remain on disk for an ordinary player. Stop waiting does not prove that a dispatched request was cancelled or uncharged; inspect Setups before retrying.

**About** opens the application identity, maintainer credit, Awakening to Reality website and optional PayPal support email. Copying the address does not send a message or make a payment.
